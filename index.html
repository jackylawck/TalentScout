🛡️ Privacy-by-Design & Data Security

🔒 零數據留存 (Zero Data Retention / ZDR)

採用純 Session-Only 記憶體運算架構。履歷（CV）與 JD 內容僅在當次會話中處理，瀏覽器關閉或重整即刻物理銷毀。
In-memory processing only. All documents and assessment histories are immediately purged upon session reset.

🔒 企業自備金鑰模式 (BYOK Support)

支援企業傳入獨立 API Key (OpenAI, DeepSeek, Gemini)，資料不留存於中間伺服器，讓企業擁有全權資安自主力。
Supports Bring-Your-Own-Key deployment, allowing organizations full oversight over their API quotas and data governance.
